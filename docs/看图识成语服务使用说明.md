# 看图识成语服务使用说明

## 功能简介

看图识成语服务是一个基于阿里通义万相模型的图片生成服务，能够根据中文成语生成相应的提示图片，用于游戏玩法。

## 特性

- 🎯 支持20个常用成语的图片生成
- 🎲 随机成语选择功能
- 🎨 使用阿里通义万相模型生成简约手绘风格图片
- 📚 内置成语含义解释
- 🔧 灵活的API接口设计

## API接口

### 1. 生成随机成语图片
```http
GET /api/game/guess-idiom/generate/random?size=1024*1024&count=1
```

### 2. 生成指定成语图片
```http
POST /api/game/guess-idiom/generate/{成语}?size=1024*1024&count=1
```

### 3. 自定义请求生成图片
```http
POST /api/game/guess-idiom/generate
Content-Type: application/json

{
    "idiom": "老马识途",
    "size": "1024*1024",
    "count": 1
}
```

### 4. 获取所有支持的成语
```http
GET /api/game/guess-idiom/idioms
```

### 5. 获取随机成语信息（不生成图片）
```http
GET /api/game/guess-idiom/random
```

## 配置说明

### 1. API密钥配置

在环境变量中配置阿里通义万相API密钥：
```bash
export DASHSCOPE_API_KEY=your_api_key_here
```

或在配置文件中配置：
```properties
dashscope.api.key=your_api_key_here
```

### 2. 支持的图片尺寸

- 1024*1024（默认）
- 512*512
- 768*768
- 1280*720

## 使用示例

### 1. 使用curl命令测试

```bash
# 生成随机成语图片
curl -X GET "http://localhost:9090/api/game/guess-idiom/generate/random"

# 生成指定成语图片
curl -X POST "http://localhost:9090/api/game/guess-idiom/generate/老马识途"

# 获取所有成语
curl -X GET "http://localhost:9090/api/game/guess-idiom/idioms"
```

### 2. 错误处理

如果遇到以下错误：
- `API密钥未配置`：请配置DASHSCOPE_API_KEY环境变量
- `不支持的成语`：请使用支持的成语列表中的成语
- `API调用失败`：请检查网络连接和API密钥是否正确

## 游戏玩法建议

1. **随机模式**：调用随机生成接口，玩家根据图片猜测成语
2. **指定模式**：选择特定成语生成图片，用于学习或测试
3. **成语学习**：结合成语含义，寓教于乐

## 技术实现

- **框架**：Spring Boot 3.2.3
- **图片生成**：阿里通义万相模型（wanx2.1-t2i-turbo）
- **文档**：Swagger UI
- **日志**：SLF4J + Logback

## 注意事项

1. 生成图片需要网络连接和有效的API密钥
2. 图片生成可能需要几秒钟时间
3. 生成的图片URL有时效性，建议及时保存
4. API调用有频率限制，请合理使用
